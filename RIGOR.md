## Notes

Sentiero is browser session recording for Ruby, self-hosted and privacy-first.
It captures user interactions with rrweb, stores them server-side with pluggable
storage, and replays sessions from a built-in dashboard. It works with any Rack
framework, and sentiero-rails adds the Rails integration. It is similar to
SpectatorSport by Ben Sheldon, but not bound to Rails.

Sentiero was built by me and an AI. The ideation and the planning went through
multiple rounds, with an AI. The implementation is the AI's. The quality reviews
and the testing were done by me and by an AI, and the security checks by an AI,
all over multiple iterations. I have read and understood the core of the code,
but later feature additions, such as the metrics, I have only skimmed. So no
human has read all of it line by line.

Sentiero is in active development. I use it in production. It is still early
days, so I reserve my vouch for now, but I recommend that you try it out and
help to improve it. Right now you are an early adopter.
